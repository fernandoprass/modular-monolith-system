# Repository Agent Guide

This repository has two main product areas:

```text
back/
front/
```

Use the rule file closest to the code you are changing.

## Backend

Backend code lives in:

```text
back/
```

Backend rules live in:

```text
back/agents.md
```

Read `back/agents.md` before backend changes.

## Frontend

Frontend code lives in:

```text
front/
```

Frontend rules live in:

```text
front/agents.md
```

Read `front/agents.md` before frontend changes.

## Shared Rule

If a task touches both areas, read both files first.

Keep replies short.
Show a plan before editing.
Wait for `go` before changing files.
