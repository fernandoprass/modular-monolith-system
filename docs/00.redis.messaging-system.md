```
           │
┌──────────┴────────────┐
│ UI Clients            │
│ - Real-time updates   │
│ - Toast notifications │
└───────────────────────┘
```

### Communication Patterns

| Pattern | Use Case | Persistence | Delivery Guarantee |
|---------|----------|-------------|-------------------|
| **Redis Streams** | Audit events, system logs | Persistent (disk) | At-least-once (with consumer groups) |
| **Redis Pub/Sub** | Real-time notifications | Ephemeral (memory) | Fire-and-forget (no guarantee if no subscribers) |

## Redis Infrastructure

### Docker Configuration

**docker-compose.yml**
```yaml
services:
  redis:
    image: redis:7-alpine
    container_name: redis
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    command: redis-server --appendonly yes --maxmemory 256mb --maxmemory-policy allkeys-lru
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 3s
      retries: 3

volumes:
  redis_data:
    driver: local
```

**Configuration Flags**:
- `--appendonly yes`: Enables AOF (Append-Only File) persistence for durability
- `--maxmemory 256mb`: Limits memory usage (adjust based on load)
- `--maxmemory-policy allkeys-lru`: Evicts least recently used keys when memory limit is reached

### Connection String

**appsettings.json** (All modules)
```json
{
  "ConnectionStrings": {
    "Redis": "localhost:6379,abortConnect=false,connectTimeout=5000,syncTimeout=5000"
  }
}
```

**Connection Options**:
- `abortConnect=false`: Allows startup even if Redis is temporarily unavailable
- `connectTimeout=5000`: 5-second connection timeout
- `syncTimeout=5000`: 5-second operation timeout

## Message Patterns

### Pattern 1: Redis Streams (Audit & System Logs)

**Characteristics**:
- **Persistent**: Messages are written to disk (AOF)
- **Ordered**: Messages maintain insertion order
- **Replayable**: Can consume from any point in the stream
- **Consumer Groups**: Multiple consumers can process messages in parallel
- **Acknowledgment**: Consumers can acknowledge message processing

**Stream Structure**:
```
Stream: audit-events
├── ID: 1234567890123-0
│   └── Field: event → {"EventId":"...", "Action":"user.created", ...}
├── ID: 1234567890124-0
│   └── Field: event → {"EventId":"...", "Action":"invoice.paid", ...}
```

**Redis CLI Commands**:
```bash
# View stream length
XLEN audit-events

# Read last 10 messages
XREVRANGE audit-events + - COUNT 10

# Read from specific ID
XREAD STREAMS audit-events 1234567890123-0

# View consumer group info
XINFO GROUPS audit-events
```

### Pattern 2: Redis Pub/Sub (Real-time Notifications)

**Characteristics**:
- **Ephemeral**: Messages exist only in memory
- **Fast**: No disk I/O, extremely low latency
- **Fire-and-forget**: If no subscribers exist, message is lost
- **No persistence**: Messages are not stored

**Channel Structure**:
```
Channel: notifications
├── Subscriber: Communication.API (SignalR Hub)
├── Subscriber: UI Client (WebSocket)
```

**Redis CLI Commands**:
```bash
# List active channels
PUBSUB CHANNELS

# Count subscribers on a channel
PUBSUB NUMSUB notifications

# Publish a test message
PUBLISH notifications '{"Type":"test","Message":"Hello"}'
```

#### 1. AuditEvent (Business Events)

**Purpose**: Captures business-critical actions for compliance and audit trails.

**Shared/Events/AuditEvent.cs**
```csharp
using Shared.Enums;

namespace Shared.Events;

/// <summary>
/// Represents a business action that must be audited for compliance.
/// Published to Redis Stream: "audit-events"
/// </summary>
public record AuditEvent
{
    /// <summary>
    /// Unique identifier for this audit event (Version 7 GUID for time ordering)
    /// </summary>
    public Guid EventId { get; init; } = Guid.CreateVersion7();

    /// <summary>
    /// Tenant/Customer/Organization context
    /// </summary>
    public Guid OrganizationId { get; init; }

    /// <summary>
    /// UTC timestamp when the event occurred
    /// </summary>
    public DateTime Timestamp { get; init; } = DateTime.UtcNow;

    /// <summary>
    /// Module that generated the event (e.g., "IAM", "Billing", "Inventory")
    /// </summary>
    public string Module { get; init; } = string.Empty;

    /// <summary>
    /// Feature that generated the event (e.g., "users", "parameters", "roles")
    /// </summary>
    public string Feature { get; init; } = string.Empty;

    /// <summary>
    /// Action performed (e.g., "created", "list", "assigned")
    /// </summary>
    public string Action { get; init; } = string.Empty;

    /// <summary>
    /// Privacy classification for filtering, masking, retention, and access rules
    /// </summary>
    public AuditPrivacyLevel PrivacyLevel { get; init; } = AuditPrivacyLevel.Medium;

    /// <summary>
    /// Description of the event (e.g., "Created a new user")
    /// </summary>
    public string Description { get; init; } = string.Empty;

    /// <summary>
    /// User who performed the action
    /// </summary>
    public Guid UserId { get; init; }

    /// <summary>
    /// Type of entity affected (e.g., "User", "Organization", "Role")
    /// </summary>
    public string Entity { get; init; } = string.Empty;

    /// <summary>
    /// ID of the affected entity
    /// </summary>
    public Guid EntityId { get; init; }

    /// <summary>
    /// Optional IP address of the originating request
    /// </summary>
    public string? IpAddress { get; init; }

    /// <summary>
    /// User agent string (e.g., browser, API client)
    /// </summary>
    public string? UserAgent { get; init; }

    /// <summary>
    /// Additional context data (serialized as JSON in database)
    /// </summary>
    public string Metadata { get; init; } = string.Empty;
}
```

**Shared/Messaging/RedisEventPublisher.cs**
```csharp
using StackExchange.Redis;
using System.Text.Json;

namespace Shared.Messaging;

public class RedisEventPublisher(IConnectionMultiplexer redis, ILogger<RedisEventPublisher> logger) : IEventPublisher
{
    private readonly IDatabase _db = redis.GetDatabase();
    private readonly ISubscriber _subscriber = redis.GetSubscriber();
    private readonly ILogger<RedisEventPublisher> _logger = logger;

    private static readonly JsonSerializerOptions JsonOptions = new()
    {
        PropertyNamingPolicy = JsonNamingPolicy.CamelCase,
        WriteIndented = false
    };

    public async Task PublishAuditEventAsync(AuditEvent auditEvent, CancellationToken cancellationToken = default)
    {
        try
        {
            var json = JsonSerializer.Serialize(auditEvent, JsonOptions);
            var streamId = await _db.StreamAddAsync("audit-events", "event", json);
            
            _logger.LogDebug("Published audit event {EventId} to stream (ID: {StreamId})", 
                auditEvent.EventId, streamId);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Failed to publish audit event {EventId}", auditEvent.EventId);
            throw;
        }
    }

    public async Task PublishSystemLogAsync(SystemLogEvent systemLog, CancellationToken cancellationToken = default)
    {
        try
        {
            var json = JsonSerializer.Serialize(systemLog, JsonOptions);
            var streamId = await _db.StreamAddAsync("system-logs", "log", json);
            
            _logger.LogDebug("Published system log {LogId} to stream (ID: {StreamId})", 
                systemLog.LogId, streamId);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Failed to publish system log {LogId}", systemLog.LogId);
            // Do NOT throw - logging failures should not break application flow
        }
    }

    public async Task PublishNotificationAsync(NotificationEvent notification, CancellationToken cancellationToken = default)
    {
        try
        {
            var json = JsonSerializer.Serialize(notification, JsonOptions);
            var subscriberCount = await _subscriber.PublishAsync("notifications", json);
            
            _logger.LogDebug("Published notification {NotificationId} to {Count} subscribers", 
                notification.NotificationId, subscriberCount);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Failed to publish notification {NotificationId}", notification.NotificationId);
            // Do NOT throw - notification failures should not break application flow
        }
    }
}
```

```csharp
            EntityId = entityId,
```

## Implementation Guidelines

### Consumer Implementation Pattern

**Sentinel.Infrastructure/BackgroundServices/AuditEventConsumer.cs**
```csharp
using StackExchange.Redis;
using System.Text.Json;
using Sentinel.Domain.Entities;
using Sentinel.Domain.Repositories;

namespace Sentinel.Infrastructure.BackgroundServices;

public class AuditEventConsumer(
    IConnectionMultiplexer redis,
    IServiceProvider serviceProvider,
    ILogger<AuditEventConsumer> logger) : BackgroundService
{
    private readonly IDatabase _db = redis.GetDatabase();
    private readonly IServiceProvider _serviceProvider = serviceProvider;
    private readonly ILogger<AuditEventConsumer> _logger = logger;
    private const string StreamName = "audit-events";
    private const string ConsumerGroup = "sentinel-audit-consumer";

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        _logger.LogInformation("Audit Event Consumer started");

        // Create consumer group if it doesn't exist
        await EnsureConsumerGroupExistsAsync();

        var lastId = ">";

        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                // Read from stream with consumer group (for load balancing)
                var entries = await _db.StreamReadGroupAsync(
                    StreamName, 
                    ConsumerGroup, 
                    "consumer-1", 
                    lastId, 
                    count: 10);

                foreach (var entry in entries)
                {
                    try
                    {
                        var json = entry.Values.FirstOrDefault(v => v.Name == "event").Value;
                        var auditEvent = JsonSerializer.Deserialize<AuditEvent>(json);

                        if (auditEvent != null)
                        {
                            await ProcessEventAsync(auditEvent, stoppingToken);

                            // Acknowledge message (removes from pending list)
                            await _db.StreamAcknowledgeAsync(StreamName, ConsumerGroup, entry.Id);
                        }
                    }
                    catch (Exception ex)
                    {
                        _logger.LogError(ex, "Error processing audit event {EntryId}", entry.Id);
                        // Message remains in pending list for retry
                    }
                }

                if (entries.Length == 0)
                {
                    await Task.Delay(1000, stoppingToken); // Polling interval
                }
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Error consuming audit events");
                await Task.Delay(5000, stoppingToken); // Backoff on error
            }
        }

        _logger.LogInformation("Audit Event Consumer stopped");
    }

    private async Task EnsureConsumerGroupExistsAsync()
    {
        try
        {
            await _db.StreamCreateConsumerGroupAsync(StreamName, ConsumerGroup, "0-0");
            _logger.LogInformation("Created consumer group {ConsumerGroup}", ConsumerGroup);
        }
        catch (RedisServerException ex) when (ex.Message.Contains("BUSYGROUP"))
        {
            // Consumer group already exists
            _logger.LogDebug("Consumer group {ConsumerGroup} already exists", ConsumerGroup);
        }
    }

    private async Task ProcessEventAsync(AuditEvent auditEvent, CancellationToken cancellationToken)
    {
        using var scope = _serviceProvider.CreateScope();
        var auditLogRepository = scope.ServiceProvider.GetRequiredService<IAuditLogRepository>();
        var unitOfWork = scope.ServiceProvider.GetRequiredService<ISentinelUnitOfWork>();

        var auditLog = AuditLog.Create(
            auditEvent.EventId,
            auditEvent.Timestamp,
            auditEvent.Module,
            auditEvent.Action,
            auditEvent.PrivacyLevel,
            auditEvent.UserId,
            auditEvent.OrganizationId,
            auditEvent.Entity,
            auditEvent.EntityId,
            auditEvent.IpAddress,
            auditEvent.UserAgent,
            auditEvent.Metadata);

        await auditLogRepository.AddAsync(auditLog, cancellationToken);
        await unitOfWork.SaveChangesAsync(cancellationToken);

        _logger.LogDebug("Persisted audit event {EventId}: {Action} on {Entity}", 
            auditEvent.EventId, auditEvent.Action, auditEvent.Entity);
    }
}
```

## Summary

| Component | Technology | Purpose | Persistence |
|-----------|-----------|---------|-------------|
| **Audit Events** | Redis Streams | Business compliance tracking | Persistent (AOF) |
| **System Logs** | Redis Streams | Technical debugging | Persistent (AOF) |
| **Notifications** | Redis Pub/Sub | Real-time UI updates | Ephemeral |
| **AuditLog Entity** | PostgreSQL JSONB | Long-term audit storage | Permanent |
| **SystemLog Entity** | PostgreSQL JSONB | Long-term log storage | Permanent |
| **Sentinel Module** | .NET Background Services | Event consumption & persistence | N/A |

**Key Design Decisions**:
- **Redis Streams** for reliable, ordered, replayable message delivery
- **Redis Pub/Sub** for fast, ephemeral real-time notifications
- **PostgreSQL JSONB** for flexible metadata storage without schema changes
- **Consumer Groups** for horizontal scaling of log processing
- **Immutable entities** (AuditLog, SystemLog) for audit integrity
