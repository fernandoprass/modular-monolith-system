# Libraries in Use

This document lists the main libraries used by the IAM module.

Versions are intentionally omitted.
Check the `.csproj` files for current versions.

## Web and API

- `Asp.Versioning.Mvc`
- `Microsoft.AspNetCore.Authentication.JwtBearer`
- `Swashbuckle.AspNetCore`
- `System.IdentityModel.Tokens.Jwt`

## Data Access

- `Microsoft.EntityFrameworkCore`
- `Microsoft.EntityFrameworkCore.Design`
- `Npgsql.EntityFrameworkCore.PostgreSQL`
- `EFCore.NamingConventions`

## Security

- `Isopoh.Cryptography.Argon2`

## Application Utilities

- `Microsoft.Extensions.Configuration`
- `Myce.FluentValidator`
- `Myce.Response`

## Testing

- `xunit`
- `Microsoft.NET.Test.Sdk`
- `xunit.runner.visualstudio`
- `coverlet.collector`
- `NSubstitute`
- `FluentAssertions`
- `Microsoft.EntityFrameworkCore.InMemory`

## Notes

- The target framework is .NET 10.
- Keep packages updated through project files.
- Do not duplicate version numbers in documentation.
