# IAM Seeders

Seeders live in:

```text
scr/02.IAM/IAM.Infrastructure/DatabaseSeeder
```

They run in development from `Program.cs`.

## Seed Order

Seed order matters:

1. Organizations
2. Parameters
3. Permissions
4. Roles
5. Role permissions

## Idempotency

Seeders must be idempotent.

Do not create duplicates.
Check if data exists before creating it.

## Main Seeders

- `SeederOrganizations`
- `SeederParameters`
- `SeederPermissions`
- `SeederRoles`
- `SeederRolePermissions`

## Permissions

Permission seed data must match `IamPermission`.

When adding a permission:

1. Add constant to `IamPermission`.
2. Add row in `SeederPermissions`.
3. Add role assignment in `SeederRolePermissions` when needed.
4. Add or update Bruno files.

## Roles

Default roles:

- `System Admin`
- `Organization Admins`
- `User`

Role-permission seeding assigns permissions after roles and permissions exist.
