# Testing

Tests live under:

```text
tests/
```

## Test Project Ownership

Ask before creating a new test project.

If no matching test project exists, confirm ownership first.

Examples:

- Application service tests belong in an Application test project.
- Domain behavior tests belong in a Domain test project.
- API middleware and filters may need an API test project.

## Test Types

Current test focus:

- validators
- application services
- repositories
- unit of work
- authorization handler behavior

## Authorization Tests

Authorization handlers should test:

- unauthenticated user fails
- system admin succeeds
- no role claims fails
- invalid role claims fail
- role with permission succeeds
- role without permission fails
- multiple roles combine permissions
- cache hit avoids service calls

## Rules

- Use `CancellationToken` when production method accepts it.
- Keep tests focused.
- Mock external dependencies.
- Do not use database integration when a unit test is enough.
