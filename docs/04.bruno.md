# Bruno API Tests

Bruno files live in:

```text
tests/bruno-collection
```

Environment files live in:

```text
tests/bruno-collection/environments
```

## Variables

Common variables:

- `server`
- `version`
- `token`

Use bearer auth:

```text
auth: bearer
```

## Folder Naming

IAM endpoint files live under:

```text
tests/bruno-collection/02.iam
```

Folders match controller areas:

- `Users`
- `Organizations`
- `Roles`
- `Permissions`
- `Parameters`

## Maintenance Rule

When adding or changing an endpoint, update Bruno files.

When adding a protected endpoint, also update:

- `IamPermission`
- `SeederPermissions`
- `SeederRolePermissions`
