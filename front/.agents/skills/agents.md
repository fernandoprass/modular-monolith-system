# Frontend Skills

This directory is `front/.agents/skills/`, relative to the repository root.

## shadcn

Read [shadcn/SKILL.md](shadcn/SKILL.md) when adding, fixing, styling, or composing shadcn/ui components.

The skill explains how to inspect project configuration, find registry components, read component documentation, and preview changes before installing or updating components. It also covers accessible forms, component composition, styling, icons, and Radix versus Base UI APIs.

Supporting guides and examples live in `shadcn/rules/` and the Markdown files linked from the skill.

Use the shadcn MCP for registry searches, examples, and add commands, as required by [the frontend rules](../../AGENTS.md). Run project CLI commands from `front/apps/`.

Follow the repository and frontend rules alongside the skill, including the plan and `go` requirement before edits. Preserve the app's established ownership of forms, notifications, and plain CSS layout.
